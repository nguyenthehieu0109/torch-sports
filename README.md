# 🔥 TORCH SPORTS

> **Nền tảng thương mại điện tử dụng cụ & trang phục thể thao tích hợp AI**

## Giới thiệu

TORCH SPORTS là nền tảng thương mại điện tử quy mô lớn chuyên bán dụng cụ và trang phục thể thao cho tất cả các môn thể thao. Nền tảng tích hợp AI thông minh giúp người dùng phối đồ, chọn dụng cụ phù hợp theo cá nhân hóa.

## Tính năng chính

- 🛒 **E-commerce toàn diện** — Quản lý sản phẩm, đơn hàng, thanh toán trực tuyến
- 🤖 **AI tích hợp** — Phối đồ thông minh, tư vấn size, chatbot, visual search
- 📦 **Quản lý kho bãi** — Multi-warehouse, auto-reorder, demand forecasting
- 📱 **Mobile App** — React Native (iOS + Android)
- 📊 **Analytics** — Dashboard real-time, báo cáo doanh thu

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js 15, TypeScript, Tailwind CSS |
| Backend | NestJS, TypeScript, Prisma |
| AI/ML | Python, FastAPI, PyTorch |
| Mobile | React Native (Expo) |
| Database | PostgreSQL, Redis, Elasticsearch, MongoDB |
| Infrastructure | Docker, Kubernetes, AWS/GCP |
